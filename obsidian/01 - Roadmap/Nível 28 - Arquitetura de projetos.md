# Nível 28 — Arquitetura de projetos

[[Bem-vindo|Início]] · [[Roadmap completo|Todos os níveis]]

## Checklist de estudo

## 28.1 — Estrutura de Pastas e Modularização

- [ ] 🔴 Organização por camadas vs por features (Feature-based Architecture)
- [ ] 🔴 Responsabilidade de diretórios: components, features, hooks, services, utils, schemas, types, constants, providers e config
- [ ] 🔴 Separação clara entre regras de negócio, acesso a dados e apresentação visual

## 28.2 — Padrões de Projeto no Front-end

- [ ] 🟡 Padrão Container / Presentational Components
- [ ] 🟡 Padrões estruturais: Service Layer, Repository, Adapter e Factory
- [ ] 🟡 Inversão de Dependência (Dependency Inversion) e isolamento de dependências externas

## 28.3 — Princípios de Design de Software (SOLID e Clean Code)

- [ ] 🔴 Princípios pragmáticos: DRY (Don't Repeat Yourself), KISS (Keep It Simple, Stupid) e YAGNI (You Aren't Gonna Need It)
- [ ] 🟡 Aplicação de SOLID no front-end moderno (especialmente Single Responsibility e Dependency Inversion)
- [ ] 🟡 Práticas de Clean Code e redução sustentável de dívida técnica
