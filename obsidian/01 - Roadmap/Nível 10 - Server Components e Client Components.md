# Nível 10 — Server Components e Client Components

[[Bem-vindo|Início]] · [[Roadmap completo|Todos os níveis]]

## Checklist de estudo

## 10.1 — Server Components

- [ ] 🔴 Execução exclusiva no servidor
- [ ] 🔴 Async Components e acesso direto a fontes de dados
- [ ] 🔴 Redução de bundle enviado ao cliente e segurança de código

## 10.2 — Client Components

- [ ] 🔴 Diretiva `'use client'` e momento de uso
- [ ] 🔴 Gerenciamento de estado (`useState`, `useReducer`) e Effects (`useEffect`)
- [ ] 🔴 Interatividade, Browser APIs e listeners de eventos (`onClick`, `onChange`)

## 10.3 — Server/Client Boundary e Composição

- [ ] 🔴 Conceito de Boundary e serialização de props
- [ ] 🔴 Composição correta: passando Server Components como `children` para Client Components
- [ ] 🔴 Prevenção de vazamento de código de servidor para o cliente

## 10.4 — Arquitetura e Internals de RSC

- [ ] 🟡 Estrutura do RSC Payload
- [ ] 🟡 Processo de Hydration no navegador
- [ ] 🟣 Streaming progressivo e funcionamento interno de reconciliação de RSC
